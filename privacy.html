Privacy Policy

Last updated 19 August 2026

This policy covers a set of private, single-user tools used by one eBay seller to test and list used computer storage hardware. The tools are not a product, are not offered to anyone else, and have no users other than their operator.

What this site does

This site hosts two static pages. One is an OAuth redirect target: after the operator grants their own eBay account's authorization, eBay sends the browser back here with a temporary code parameter in the address bar. The page reads that value from the address bar and displays it so it can be copied into a local command-line tool.

The page runs entirely in the browser. It has no server-side component, no database, and no analytics. It does not transmit the authorization code, or anything else, anywhere. It sets no cookies and uses no local storage.

What is collected

Nothing. This site collects, stores, and shares no personal information. There is no contact form, no account, no tracking, and no advertising.

Because the pages are served by GitHub Pages, GitHub may log requests (including IP addresses) as part of operating its own infrastructure. That logging is GitHub's, not this site's, and is described in the GitHub Privacy Statement.

eBay data

The associated command-line tools access the operator's own eBay seller account through the official eBay REST APIs, using credentials the operator issued to themselves. Access tokens are stored only on the operator's own computer, in a file readable only by that user account. No eBay data belonging to any other person is requested, received, or stored, and no eBay data is shared with any third party.

Buyer information arising from an ordinary sale is handled inside eBay's own systems under eBay's policies. These tools do not export it.

Retention and deletion

Locally stored tokens can be revoked at any time from the operator's eBay account security settings, and deleted by removing the local credential file. There is nothing held on this site to delete.

Contact

Questions about this policy can be raised as an issue on the project repository.
